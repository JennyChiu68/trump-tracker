# 特朗普发言追踪

面向金十数据移动端的固定快照工具，帮助交易者从特朗普发言中识别两类信息：行情异动和老话重提。当前版本不轮询、不在后台更新数据，也不公开展示全量发言归档。

## 发布结构

- `index.html` / `styles.css` / `app.js`：移动端工作台。
- `bootstrap.js`：HTTP 环境只加载接口数据；`file://` 环境才加载离线快照，避免重复下载。
- `data/release-feed.json`：通过内容质量门禁的发布数据。
- `snapshot.js`：与发布数据一致的离线预览快照。
- `server.js`：固定快照服务，包含 gzip、ETag、缓存、安全响应头、健康检查和统一错误处理。

原始抓取归档、人工补充底稿、旧版全量页面和历史实验版本不进入公开仓库，避免重新暴露产品已屏蔽的内容。它们只保存在内部数据更新环境中。

## 内容门禁

发布构建采用“宁缺毋错”原则。一条记录只有同时满足以下条件才会进入页面：

1. 可判定为特朗普本人发言，不是转发、图片描述、视频字幕或纯链接。
2. 中文为人工补充或高置信度规则转换，不使用“相关问题”等占位式模板。
3. 中文中的伊朗、霍尔木兹、关税、美联储、能源、公司等关键语义可在英文原文中找到对应锚点。
4. 不含涉华、中国领导人、人民币、贸易战等屏蔽内容。
5. 系统分析不输出买入、卖出、做多或做空建议。

原始归档约 3,900 条；当前发布快照保留 252 条通过门禁的中文记录，其中行情异动包含 47 条历史记录，老话重提形成 3 组观点。数量会随原始快照和质检规则变化。

## 本地运行

```bash
npm run build
npm test
npm start
```

预览地址：`http://127.0.0.1:4173/`

健康检查：`http://127.0.0.1:4173/healthz`

也可以直接打开 `index.html`，此时页面使用 `snapshot.js`，不会访问接口。

## 更新固定快照

以下命令仅适用于具备内部原始数据的更新环境。抓取和合并原始归档后，必须重新构建并通过全部测试：

```bash
node scripts/fetch-trumps-truth-archive.js --from 2026-07-15 --to 2026-07-20 --out data/trump-feed.delta.json
node scripts/merge-trump-feed.js data/trump-feed.json data/trump-feed.delta.json data/trump-feed.json
npm run build
npm test
```

`scripts/audit-content.js` 会检查发言归属、翻译对齐、涉华过滤、模板碰撞和交易建议；`scripts/smoke-ui.js` 校验两个核心模块、搜索、历史列表以及全量归档未公开；`scripts/test-server.js` 校验接口、缓存、安全响应头和 HTTP 行为。

## 数据说明

当前原始快照覆盖 `2026-01-01` 至 `2026-07-20`，归档中最新发帖时间为 `2026-07-19 22:32`。Truth Social 直连接口在当前环境受 Cloudflare 限制，因此社媒数据来自 Trump’s Truth 第三方公开归档；口头发言补充来自金十快讯截图。发布数据是固定快照，不代表实时、完整或未经筛选的全部发言。
